Manually trigger an Obsidian note update without writing a dev log.
Usage: /update [note] [content to add or change]

First read CLAUDE.md in the current directory to find the project vault folder.
Then read the specified note from that vault folder.
Make the requested change precisely — do not rewrite the whole note.
Confirm: "✅ Updated [note name]"

Use this for quick manual corrections, adding context, or filling in gaps.
